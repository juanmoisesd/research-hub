# Contributing to Open Research Hub — Latin America

Thank you for your interest in open research! 🌎

## Ways to Contribute

### 📊 Add Your Dataset
- Open a [feature request](../../issues/new?template=feature_request.md) to suggest a new dataset for inclusion
- Provide: title, DOI, source, description, and relevance to Latin America

### 🐛 Report Issues
- Broken links, outdated DOIs, or incorrect metadata → [bug report](../../issues/new?template=bug_report.md)

### 💻 Improve the Portal
1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Commit your changes
4. Open a Pull Request

### 🌐 Translations
- Help translate the portal into Spanish or Portuguese

### 💬 Discussions
- Join the conversation in [GitHub Discussions](../../discussions)
