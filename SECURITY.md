# Security Policy

## Supported Versions

| Version | Supported |
|---------|----------|
| latest  | ✅        |

## Reporting a Vulnerability

Email **jmsernatuya@gmail.com** with subject line:
`[SECURITY] Open Research Hub`

Please **do not** open a public GitHub issue for security vulnerabilities.

We will acknowledge your report within **48 hours** and provide a detailed response within **7 days**.

## Scope

- Malicious content injected into the portal or its dependencies
- Data integrity issues that could mislead researchers
- Privacy violations involving contributor or user data
